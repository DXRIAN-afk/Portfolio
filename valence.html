Das Projekt

Valence ist ein browserbasierter Code-Editor für Einsteiger und Fortgeschrittene. Er verbindet einen Mehrsprachen-Editor, eine sofortige Live-Ausführung und ein einfaches Ordnersystem in einer einzigen, ruhigen Oberfläche — ganz ohne Installation.

Drei Sprachen, ein Editor

HTML, JavaScript und Python in derselben Oberfläche schreiben — mit Syntaxhervorhebung und Zeilennummern.

Sofort ausführen

Ein Klick auf „Ausführen" zeigt Live-Vorschau und Konsole. Python läuft direkt im Browser via Pyodide.

Ordner & Dateien

Projekte in Ordnern organisieren, umbenennen und per Drag & Drop verschieben — wie in einer echten IDE.

Automatisch gespeichert

Deine Dateien bleiben erhalten — auch nachdem du den Tab schließt oder den Browser neu startest.

Eigene Dateien öffnen

Bestehende .html-, .js- oder .py-Dateien laden, bearbeiten und wieder als Datei herunterladen.

Für jedes Level geeignet

Vom ersten „Hallo Welt" bis zu größeren Projekten — Valence wächst mit deinem Wissen mit.

So funktioniert's

Drei Schritte, kein Setup.

1

Schreiben

Code in den Editor eingeben oder eine der Vorlagen für HTML, JavaScript oder Python nutzen.

2

Ausführen

Mit Strg/Cmd + Enter oder einem Klick auf „Ausführen" siehst du das Ergebnis sofort in Vorschau oder Konsole.

3

Organisieren

Datei benennen, in einen Ordner legen und jederzeit wiederfinden — automatisch gespeichert.

Programmiersprachen lernen

Schritt-für-Schritt-Anleitungen für HTML, JavaScript und Python. Jedes Beispiel lässt sich mit einem Klick direkt im Editor ausprobieren.

Bereit loszulegen?

Kein Account, keine Installation — der Editor läuft direkt in deinem Browser.
